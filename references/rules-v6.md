# 课题组个人报销规则（V6；个人明细展示约定 2026-09-22 r4）

规则依据：Tang Group 集中报销手册 V6 的“集中报销准备工作”“常见问题汇总”“报销明细表（个人）”；课题组语音整理稿仅作补充。此文件记录本 skill 的固定检查口径，不能代替负责人或财务审核。税务平台验真不在第一版范围内。

个人明细展示约定来源：用户 2026-09-22 对本 skill 的更新要求。网络服务实例中，用户确认当次上海贝锐发票购买向日葵；[贝锐官网](https://sunlogin.oray.com/product/feat) 可核对公司经营向日葵等产品，但仅凭公司名称不能识别某一张发票的具体产品。

2026-09-22 r3 更正来源：用户本次明确纠正“满 1000 元且非对公不可报销”的旧口径，要求正常报销并办理高值耗材登记；待核实票正常编号、计入可读取金额、重命名并在 Excel 备注列原因；一次用户委托只形成一个正式版本，同次制作迭代不递增正式版本，之后补件续跑才递增。此更正优先于本文件此前的冲突表述。

2026-09-22 r4 更正来源：用户进一步明确，高值耗材登记仅按材料类商品**含税单价满 1000 元**判断，不能以整张发票总价触发；**单张发票价税合计超过 1000 元**须有支付记录，不限个人垫付或对公。相同类别、相同简要品名的发票须连续排列并依次编号；多张发票的开票公司与开票日期均相同，应在这些发票的 Excel 备注中标注同一组。r4 覆盖 r3 中“整票满 1000 元即高值耗材登记”的旧表述。

## 明细与金额

- 一张发票对应明细表一行；按类别排列、全局连续编号。电子原票副本命名为`序号-简要名称-金额元`。已填写类别中，材料费、快递费、交通费、书籍、差旅费按 V6 顺序；可按实际费用增设文印、测试化验加工、版面/审稿、查收查引/专利等类别；空类别删除。保留“报销单制作”区域。
- 个人明细把实际商品明显属于日用品或科研与生活两用的票单列“日用及两用物品”，不归入实验材料费。暂计金额中保留该票，同时在备注与补件提醒标出科研用途待负责人确认；确认前不能标为可提交。商品行入库和高值门槛照常检查。不能仅凭发票税收分类推断实际用途。
- 每票备注简列已经匹配的附件，如行程单、支付记录截图、论文录用通知，重复附件注明份数；未匹配的附件不能标为已提供。保留缺件、商品手续与其他复核备注。中文使用黑体，英文和数字使用 Times New Roman，所有文字为黑色；分类、列和合计标题加粗；标题底色取 V6 原版的浅青绿色（约 `#E2EFDA`）。
- 同类发票的简要名称去掉末尾单位和无关型号，使用数字 `1、2、3…` 依序区分，不沿用旧文件名中的 A/B 等尾号；同一类别、同一简要品名须连续排列，不得让螺丝1—8等系列中间穿插其他品名。类别内先按品名成组，再在各品名组内排序。一张发票对应一个全局编号，Excel 名称与新副本文件名同步。网络/软件服务还须明确产品或平台主体；核对订单、票面、开票方官方资料或报销人说明，不能把公司旗下任一产品直接视为票面所购产品。
- 同一开票公司、同一开票日期的多张发票视作一组；优先用销售方税号判定同一公司，辅以票面销售方名称核对，在每张组内发票的 Excel 备注写相同组号、张数、公司及日期。不同开票公司或日期不可仅凭商品相似分组；销售方证据不足时不猜测。
- 票面正文优先于旧文件名。票面与文件名、支付记录冲突时标待核实，使用有原件依据的金额暂计。个人垫付单张满 1000 元不因此判为不可报销。单张发票价税合计**超过 1000 元**须有支付记录；对公票均需付款依据；报销金额与付款凭证冲突须核对。高值耗材登记只按材料类商品含税单价判断，不按整票总价判断。
- 缺附件和待核实的票都进入 Excel、全局编号、正常命名；有可靠票面或已证实申报金额时纳入暂计，在备注写明缺件及待核实原因。金额无法可靠提取时留空、不编造金额，编号保留，文件名标金额待核。确认不可报销的票不计入暂计。PDF 可列补件事项，但待核实原因只在 Excel 备注中集中呈现。未解决问题前不能标为可提交。
- 首次委托正式包为 v1。同一次委托为复核而再次构建，应更新同一正式版本并留存可追溯的中间尝试，不占用 v2；下一次用户补件续跑才发布 v2，旧正式版本保留。
- 发票日期只设置本次截止日；晚于截止日待核实，早于截止日所在年度的票提醒人工核对。可选历史目录只用于“疑似重复”提示，不据目录出现就断言已报销。

## 抬头、商品与材料手续

- 可读取的普通增值税发票应有购买方“西安交通大学”和税号`12100000435230200R`。确认缺失或不符即列不可报销；无法读清则待核实。没有学校抬头栏的客票、出租车票等按票种检查。
- 发票商品名称与购买物品须相符。V6 明确指出“数据线”“手机充电线”“计算机”等不可报销；“化学试剂助剂”“化学合成材料”等实验用品问题和两用物品须提示负责人确认，不能仅据模糊 OCR 自动定性。
- 对材料费及日用/两用材料票的**每一商品明细行**计算含税行金额：满 500 元提示该商品需入库；含税单价满 1000 元提示具体商品高值耗材手续。整票总价不触发高值耗材登记。涉及门槛的发票可在其**同品名组内**后排，不能为此打散同类发票；入库备注仍点名达到门槛的具体商品，不把同票其他低额商品判为需入库。行数据无法可靠提取时标待核实，但保留已核实的票面金额和编号。

## 附件与线下动作

| 情形 | 检查或提醒 |
| --- | --- |
| 快递费 | 运单或运费清单。 |
| 打印费 | 打印清单；金额超过 200 元还需打印内容证明；发票内容不得写“论文”。 |
| 网约车 | 行程单；起终点与科研公务有关。涉及车站、机场的行程与差旅归在一起。 |
| 西安地铁 | 电子票须对应行程列表截图；纸票与出租车票分开粘贴；储值卡票据不报。 |
| 出租车纸票 | 仅西安市票；A4 纸最多 8 张，铅笔写起终点。 |
| 火车、飞机、住宿、会议 | 同一行程票据和会议材料放在一起；差旅起终点须为西安；机票、高铁和注册费发票需双份。负责人确认具体附件。 |
| 版面费、审稿费 | 发票、支付记录、缴费通知、审稿/录用通知、论文首页。 |
| 测试费 | 测试清单或报告；大额费用合同须由负责人判断。 |
| 查收查引 | 票据；金额超过 200 元需清单、超过 1000 元需支付记录。 |
| 书籍 | 若发票未写书名，在纸质发票 A4 空白处写明书名。 |
| 定额/手撕发票 | 盖有同一发票专用章的销货清单，金额须一致，材料粘在一张 A4 纸。 |
| 纸质票据扫描件 | 扫描件只作对照；按 V6 粘贴、打印并提交纸质原件。 |

上述附件名称可因商家格式不同而变化。只在有明确、唯一的文件关联时自动判为“已提供”，其余列缺件或待人工核对。
