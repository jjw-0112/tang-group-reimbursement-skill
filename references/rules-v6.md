# 课题组个人报销规则（V6）

规则依据：Tang Group 集中报销手册 V6 的“集中报销准备工作”“常见问题汇总”“报销明细表（个人）”；课题组语音整理稿仅作补充。此文件记录本 skill 的固定检查口径，不能代替负责人或财务审核。税务平台验真不在第一版范围内。

## 明细与金额

- 一张发票对应明细表一行；按类别排列、全局连续编号。电子原票副本命名为`序号-简要名称-金额元`。已填写类别中，材料费、快递费、交通费、书籍、差旅费按 V6 顺序；可按实际费用增设文印、测试化验加工、版面/审稿、查收查引/专利等类别；空类别删除。保留“报销单制作”区域。
- 票面正文优先于旧文件名。票面与文件名、支付记录冲突时先待核实。满 1000 元发票，按支付凭证确认报销金额；个人垫付单张发票满 1000 元按 V6 列不可报销，特殊情况咨询负责人。对公转账可以满 1000 元，所有对公票均需有付款依据。
- 可确认但缺附件的票暂计入 Excel，备注“缺件”；未补齐不能标为可提交。待核实和不可报销票不计入暂计金额。
- 发票日期只设置本次截止日；晚于截止日待核实，早于截止日所在年度的票提醒人工核对。可选历史目录只用于“疑似重复”提示，不据目录出现就断言已报销。

## 抬头、商品与材料手续

- 可读取的普通增值税发票应有购买方“西安交通大学”和税号`12100000435230200R`。确认缺失或不符即列不可报销；无法读清则待核实。没有学校抬头栏的客票、出租车票等按票种检查。
- 发票商品名称与购买物品须相符。V6 明确指出“数据线”“手机充电线”“计算机”等不可报销；“化学试剂助剂”“化学合成材料”等实验用品问题和两用物品须提示负责人确认，不能仅据模糊 OCR 自动定性。
- 对材料费发票的**每一商品明细行**计算含税行金额：满 500 元提示该商品需入库；含税单价满 1000 元提示高值耗材手续。只把涉及门槛的整张发票排到材料费组后部，备注点名具体商品。同票未达门槛的其他商品不因此一并认定要入库。若行数据无法可靠提取或核对，列待核实。

## 附件与线下动作

| 情形 | 检查或提醒 |
| --- | --- |
| 快递费 | 运单或运费清单。 |
| 打印费 | 打印清单；金额超过 200 元还需打印内容证明；发票内容不得写“论文”。 |
| 网约车 | 行程单；起终点与科研公务有关。涉及车站、机场的行程与差旅归在一起。 |
| 西安地铁 | 电子票须对应行程列表截图；纸票与出租车票分开粘贴；储值卡票据不报。 |
| 出租车纸票 | 仅西安市票；A4 纸最多 8 张，铅笔写起终点。 |
| 火车、飞机、住宿、会议 | 同一行程票据和会议材料放在一起；差旅起终点须为西安；机票、高铁和注册费发票需双份。负责人确认具体附件。 |
| 版面费、审稿费 | 发票、支付记录、缴费通知、审稿/录用通知、论文首页。 |
| 测试费 | 测试清单或报告；大额费用合同须由负责人判断。 |
| 查收查引 | 票据；金额超过 200 元需清单、超过 1000 元需支付记录。 |
| 书籍 | 若发票未写书名，在纸质发票 A4 空白处写明书名。 |
| 定额/手撕发票 | 盖有同一发票专用章的销货清单，金额须一致，材料粘在一张 A4 纸。 |
| 纸质票据扫描件 | 扫描件只作对照；按 V6 粘贴、打印并提交纸质原件。 |

上述附件名称可因商家格式不同而变化。只在有明确、唯一的文件关联时自动判为“已提供”，其余列缺件或待人工核对。
